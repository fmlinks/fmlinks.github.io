Install heartvolmesh ↗
heartvolmesh / quick start
git clone https://github.com/fmlinks/HeartVolMesh.git
cd HeartVolMesh
python bootstrap.py --workspace ./workspace
python run_inference.py --workspace ./workspace \
  --image ./CTA.nii.gz --output ./result
Download the release bundles ↗

Windows RTX 5090 was tested in a fresh environment. The installer provides a driver-aware RTX 3090 route; that hardware has not been directly tested. Review heart coverage and native CT overlays for each new dataset. This is a research release.
